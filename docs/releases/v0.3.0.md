# SRW Z Special Disc English v0.3.0

First English story test build, retaining all menu, Library and UI work from v0.2.24.

- Translate all 45 story chunks: 7,511 dialogue rows, 71 scene captions and the chunk-66 demo scene.
- Apply reviewed names and 796 shorter fits within three-line boxes and native per-chunk text budgets.
- Retain translated mission conditions, episode/location title graphics, compact terrain labels, intermission/Bazaar artwork, and squad naming/confirmation fixes.
- Package a full clean-disc patch with Retro Trans's canonical manifest, validation report and checksums.

**In-game rendering and playthrough validation are pending.** This is an AI-assisted translation test build. Other battle captions, suspend-message integration, one save summary and remaining artwork still need work. Native internal labels and hidden `???` conditions are intentionally preserved.

Use the Japanese Special Disc **SLPS-25920**, a 3,791,781,888-byte logical DVD image. Source SHA-256:

Apply `SRWZ-SP-English-v0.3.0.xdelta` with [Retro Trans](https://github.com/retro-trans/retro-trans-tools/releases/latest), Delta Patcher or xdelta3. Extract CHD containers before manual patching. This full patch does not apply to the main SRW Z or an earlier translated Special Disc image. Automatic Retro Trans discovery requires a public repository and release.

Assets: the xdelta patch, `BUILD-MANIFEST.json`, `VALIDATION.json`, `SHA256SUMS.txt`, `README-v0.3.0.txt` and `CHANGELOG-v0.3.0.txt`. GitHub's source archives contain tools and English review exports; they are not game images or a complete private build snapshot.

Binary round-trip and Retro Trans recognition/application are checked before publication. These checks do not establish runtime acceptance. See [README](https://github.com/retro-trans/SRW-Z-Special-Disc#readme) for coverage, instructions and known limitations.
