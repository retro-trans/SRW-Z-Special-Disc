# SRW Z Special Disc English v0.3.16

Cumulative battle-dialogue and UI update, retaining the story, Library and menu translations from v0.3.0.

- Complete the player-facing indexed battle-caption set: 25,521 unique texts at 58,880 occurrences. Translate all 4,297 Battle Theater speaker-name slots, including Roger.
- Include all 57 post-save scenes: 296 unique messages at 379 references, including Rand and Mel.
- Fix story text rendering, Story Mode reward panels and stray glyphs, Challenge briefing overflow, Search help layout, character setup labels, and scripted Grendizer names.
- Translate battle banners and combat forecast icons, and standardize Hyakki Empire terminology.
- Change the stage-entry label from Ep. to Stage and match its lettering height and baseline to the number.

**This remains an AI-assisted translation test build.** Full playthrough and in-game acceptance of the latest fixes are pending. Most newly added battle English is reused from source-matched SRW-Z translations, without a new line-by-line proofreading pass. One save summary, unbound archive text and remaining artwork still need work. Suppressed internal production notes and internal story labels remain intentionally native.

## Apply the patch

Apply `SRWZ-SP-English-v0.3.16.xdelta` to the clean Japanese **SLPS-25920 Special Disc**, using [Retro Trans](https://github.com/retro-trans/retro-trans-tools/releases/latest), Delta Patcher or xdelta3. In Retro Trans, refresh the catalog and select **0.3.16 / Latest**. This is a full patch from the original disc; do not apply it to an earlier translated ISO or the main SRW Z game. Extract CHD containers before manual patching. Cold boot the patched ISO instead of loading an old emulator state.

Both source and target images are **3,791,781,888 bytes**.
