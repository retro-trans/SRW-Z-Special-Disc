English translation of **Super Robot Taisen Z Special Disc** for PS2, the Japanese **SLPS-25920** release. Includes a full patch from the original game and an upgrade from the published English **v0.3.0** image.

Also see [SRW Z releases](https://github.com/retro-trans/SRW-Z/releases).

### Apply

**The easiest way:** [Retro Trans](https://github.com/retro-trans/retro-trans-tools) provides a desktop interface for applying translation patches. Download the app from its Releases page, refresh the catalog, choose the **Automatic** tab and select your source game image (`.iso` or supported `.chd`). After the app identifies it, select **0.3.16 / Latest** and click **Patch**.

**Other ways:** [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) accepts the same `.xdelta` files. Select your unpacked `.bin`/`.iso` as the original file and the appropriate patch.

**Command line:** Get [xdelta3 here](https://github.com/jmacd/xdelta). `chdman.exe` is included with [MAME](https://www.mamedev.org/release.html); you do not need to install or run MAME.

You need your own Japanese Special Disc image, or the matching published English v0.3.0 image for an upgrade. These patches are for **Special Disc**, which is a separate game from the main SRW Z.

| Your source image | Patch |
| --- | --- |
| Original Japanese Special Disc, SLPS-25920 | `SRWZ-SP-English-v0.3.16.xdelta` |
| English Special Disc v0.3.0 | `SRWZ-SP-English-v0.3.0-to-v0.3.16.xdelta` |

**Original Japanese Special Disc:**

```sh
xdelta3 -d -s "Super Robot Taisen Z Special Disc (Japan).iso" SRWZ-SP-English-v0.3.16.xdelta "SRW Z Special Disc English v0.3.16.iso"
```

**Already on v0.3.0?** Use the smaller upgrade patch:

```sh
xdelta3 -d -s "SRW Z Special Disc English v0.3.0.iso" SRWZ-SP-English-v0.3.0-to-v0.3.16.xdelta "SRW Z Special Disc English v0.3.16.iso"
```

**If you have a `.chd`**, Retro Trans Automatic can handle supported inputs. For manual patching, check its type first:

```sh
chdman info -i "your-game.chd"
```

For a **DVD CHD**, extract an ISO:

```sh
chdman extractdvd -i "your-game.chd" -o game.iso
```

For a **single MODE1/2048 data-track CHD**, extract a BIN:

```sh
chdman extractcd -i "your-game.chd" -o tmp.cue -ob game.bin
```

Apply the matching patch to the extracted `game.iso` or `game.bin`. If the patcher reports a checksum mismatch, check your source version against the hashes in `README-v0.3.16.txt`. Do not disable source verification. The upgrade requires the exact published v0.3.0 output; a local test build with the same version label may differ. Full and upgrade patches produce identical v0.3.16 output, **3,791,781,888 bytes**.

### What changed since v0.3.0

- **Indexed battle captions completed.** All 25,521 player-facing caption identities are translated at 58,880 occurrences. All 4,297 Battle Theater speaker-name slots are English, including Roger.
- **Post-save dialogue completed.** Includes all 57 scenes: 296 unique messages at 379 references, including Rand and Mel.
- **Story and menu rendering corrected.** Fixes overlapping story text, Story Mode reward-panel alignment and stray glyphs, Challenge briefing overflow, and Search help layout.
- **More labels and artwork translated.** Adds character setup labels, scripted Grendizer names, battle banners and combat forecast icons. Standardizes Hyakki Empire terminology.
- **Stage headings resized and aligned.** Replaces the title-card `Ep.` prefix with `Stage`, matching the number's lettering height and baseline.
- **Cumulative translation retained.** Preserves the story, Library, menu, mission-condition, terrain-label, squad and Bazaar translations from previous builds.

Both patches were applied to their specified source images and matched the complete v0.3.16 output SHA-256. Retro Trans recognition and application passed for the clean-disc route, including the tested single-track CHD, and for the v0.3.0 upgrade. The public catalog offers both direct routes. `BUILD-MANIFEST.json`, `VALIDATION.json` and `SHA256SUMS.txt` follow the Retro Trans catalog format.

### Testing status

**This remains a translation test build.** Automated checks and patch round trips have passed; full playthrough and in-game acceptance of the latest fixes remain pending. Please cold boot the new ISO to check story text, battle captions, post-save scenes, reward panels and Stage headings. Emulator save states can retain old code and resources.

One save summary, unbound archive text, remaining artwork and broader proofreading still need work. Internal story labels and 382 suppressed production-note records intentionally remain native. Completion of the indexed battle-caption set does not mean every text surface has been translated.

### What's included

English story dialogue across all 45 story chunks; indexed battle captions and Battle Theater speaker names; all 57 post-save scenes; pilot, mech and weapon text; Library and glossary entries; Strategy Q&A; Scenario Chart text; mission conditions; title cards; narration; and menu/status text. The release provides a full clean-disc patch and an upgrade from the published v0.3.0 image.

Versioned README and changelog files are included with the patch assets. See the [project README](https://github.com/retro-trans/SRW-Z-Special-Disc#readme) for detailed coverage and source-image hashes.

### How it was translated

This is a **machine-assisted translation**, produced with large language models and edited, with terminology and reusable translations drawn from SRW Z. Most newly added battle English reuses exact source-matched SRW-Z translations and has not received a fresh line-by-line proofreading pass. Inherited Library prose also needs broader editorial review.
