English translation of **Super Robot Taisen Z Special Disc** for PS2, the Japanese **SLPS-25920** release. Includes a full patch from the original game and upgrades from the published English **v0.3.0** and **v0.3.16** images.

Also see [SRW Z releases](https://github.com/retro-trans/SRW-Z/releases).

### Apply

**The easiest way:** [Retro Trans](https://github.com/retro-trans/retro-trans-tools) provides a desktop interface for applying translation patches. Download the app from its Releases page, refresh the catalog, choose the **Automatic** tab and select your source game image (`.iso` or supported `.chd`). After the app identifies it, select **0.3.20 / Latest** and click **Patch**.

**Other ways:** [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) accepts the same `.xdelta` files. Select your unpacked `.bin`/`.iso` as the original file and the appropriate patch.

**Command line:** Get [xdelta3 here](https://github.com/jmacd/xdelta). `chdman.exe` is included with [MAME](https://www.mamedev.org/release.html); you do not need to install or run MAME.

You need your own Japanese Special Disc image, or a matching published English v0.3.0/v0.3.16 image for an upgrade. These patches are for **Special Disc**, which is a separate game from the main SRW Z.

| Your source image | Patch |
| --- | --- |
| Original Japanese Special Disc, SLPS-25920 | `SRWZ-SP-English-v0.3.20.xdelta` |
| English Special Disc v0.3.0 | `SRWZ-SP-English-v0.3.0-to-v0.3.20.xdelta` |
| English Special Disc v0.3.16 | `SRWZ-SP-English-v0.3.16-to-v0.3.20.xdelta` |

**Original Japanese Special Disc:**

```sh
xdelta3 -d -s "Super Robot Taisen Z Special Disc (Japan).iso" SRWZ-SP-English-v0.3.20.xdelta "SRW Z Special Disc English v0.3.20.iso"
```

**Already on v0.3.0?** Use the smaller upgrade patch:

```sh
xdelta3 -d -s "SRW Z Special Disc English v0.3.0.iso" SRWZ-SP-English-v0.3.0-to-v0.3.20.xdelta "SRW Z Special Disc English v0.3.20.iso"
```

**Already on v0.3.16?** Use its direct upgrade:

```sh
xdelta3 -d -s "SRW Z Special Disc English v0.3.16.iso" SRWZ-SP-English-v0.3.16-to-v0.3.20.xdelta "SRW Z Special Disc English v0.3.20.iso"
```

**If you have a `.chd`**, Retro Trans Automatic can handle supported inputs. For manual patching, check its type first:

```sh
chdman info -i "your-game.chd"
```

For a **DVD CHD**, extract an ISO:

```sh
chdman extractdvd -i "your-game.chd" -o game.iso
```

For a **single MODE1/2048 data-track CHD**, extract a BIN:

```sh
chdman extractcd -i "your-game.chd" -o tmp.cue -ob game.bin
```

Apply the matching patch to the extracted `game.iso` or `game.bin`. If the patcher reports a checksum mismatch, check your source version against the hashes in `README-v0.3.20.txt`. Do not disable source verification. Each upgrade requires its exact published v0.3.0 or v0.3.16 output; a local test build with the same version label may differ. Full and both upgrade patches produce identical v0.3.20 output, **3,791,781,888 bytes**.

### What changed since v0.3.16

- **Back Log rendering repaired.** English punctuation and digits no longer get interpreted as control codes that break or overprint the displayed rows.
- **Title artwork translated.** Uses the main SRW Z English logo, with the Special Disc subtitle and matching glow artwork translated in both title appearances.
- **Special Theater menu translated.** Adds English for the header and Quit Messages, Movie Gallery, Design Gallery, Battle Theater and Wallpapers banners.
- **Battle Viewer help and controls translated.** Covers Start, Save, Load, BGM Setup, vibration and Exit help, plus the three BGM-source choices and descriptions. Adds ATK/CNT icons, Start Battle, and B/P/D HIT indicators for Barrier, Barrier Pierce and Defend.
- **Weapon terminology corrected.** Gabthley's Fedain Rifle and rapid variant now use Fedayeen Rifle consistently.
- **Previous translation retained.** Includes all story, indexed battle captions, Battle Theater names, post-save scenes, Library, menus and layout fixes from v0.3.16.

All three patches are built and reconstructed with Retro Trans's release tooling against their exact source images. The full reconstructed outputs must match the v0.3.20 SHA-256. The package includes the canonical manifest, validation record, checksum list, versioned README and changelog. Automated checks preserve unrelated disc data, native sprite geometry and palettes.

### Testing status

**This remains a translation test build.** Automated checks and patch round trips have passed; full playthrough and in-game acceptance of the latest fixes remain pending. Please cold boot the new ISO and check Back Log text, both title screens, Special Theater banners and Battle Viewer controls and help. Load an in-game memory-card save. Emulator save states can retain old code and resources.

One save summary, unbound archive text, remaining artwork and broader proofreading still need work. Internal story labels and 382 suppressed production-note records intentionally remain native. Completion of the indexed battle-caption set does not mean every text surface has been translated.

### What's included

English story dialogue across all 45 story chunks; indexed battle captions and Battle Theater speaker names; all 57 post-save scenes; pilot, mech and weapon text; Library and glossary entries; Strategy Q&A; Scenario Chart text; mission conditions; title cards; narration; and menu/status text. The release provides a full clean-disc patch and upgrades from the published v0.3.0 and v0.3.16 images.

Versioned README and changelog files are included with the patch assets. See the [project README](https://github.com/retro-trans/SRW-Z-Special-Disc#readme) for detailed coverage and source-image hashes.

### How it was translated

This is a **machine-assisted translation**, produced with large language models and edited, with terminology and reusable translations drawn from SRW Z. Most newly added battle English reuses exact source-matched SRW-Z translations and has not received a fresh line-by-line proofreading pass. Inherited Library prose also needs broader editorial review.
